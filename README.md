# Prototype Jeu de Course

Mini-jeu de course en HTML5 / JavaScript jouable sur ordinateur et smartphone.

🔗 **Jouer en ligne :** https://jlb30350.github.io/jeu-courses/

## Commandes

### Sur PC (clavier)
* **Flèche Haut (`↑`)** : Accélérer
* **Flèche Bas (`↓`)** : Freiner / Marche arrière
* **Flèche Gauche (`←`)** : Tourner à gauche
* **Flèche Droite (`→`)** : Tourner à droite

### Sur Smartphone / Tablette (tactile)
* **◀** : Tourner à gauche
* **▶** : Tourner à droite
* **Gaz** : Accélérer
* **Frein** : Freiner / Marche arrière

> *Conseil sur téléphone : passe l'écran en mode paysage (horizontal) pour un meilleur confort de pilotage.*

## Règles de piste
* Rester sur le bitume gris permet d'atteindre la vitesse maximale.
* Sortir dans l'herbe verte ralentit automatiquement le véhicule.
